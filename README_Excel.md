## 📁 Projects

---

### 1. 🚲 Bike Buyers — Customer Analysis Dashboard

**File:** `Formula_Excel_Template_project.xlsm`

Analysis of 1,000+ customer records to identify what drives bike purchase decisions.

**Key Findings:**
- Customers with 0–1 mile commute have 68% purchase rate
- Middle-aged customers (31–54) account for 54% of purchases
- Male buyers earn $5K more on average than non-buyers

**Skills:** Pivot Tables · Slicers · Interactive Charts · Customer Segmentation

---

### 2. 🧹 US Presidents — Data Cleaning

**File:** `Data_Cleaning_Excel_Project.xlsx`

Professional data cleaning on a 45-row historical dataset of US Presidents.

**Issues Fixed:**
- Removed duplicate row (Woodrow Wilson)
- Converted Excel serial numbers to proper dates using `TEXT()`
- Removed extra whitespace with `TRIM()`
- Standardized party names with `PROPER(TRIM())`

**Skills:** TRIM · TEXT · PROPER · Remove Duplicates · Data Standardization

---

### 3. 🔍 HR Lookup System — XLOOKUP & Advanced Formulas

**File:** `Formula_Excel_Template_project.xlsm`

Dynamic employee data retrieval system on Dunder Mifflin HR dataset (9 employees).

**Formulas Used:**

| Formula | Use Case |
|---------|----------|
| `XLOOKUP` | Exact, partial, wildcard, multi-column lookup |
| `INDEX/MATCH` | Flexible two-way lookup |
| `IF / IFS` | Conditional classification |
| `SUMIF / COUNTIF` | Conditional aggregation |
| `MAX / MIN` | Salary range detection |
| `LEN` | Data validation (SSN length check) |
| `TRIM / SUBSTITUTE` | Text cleaning |
| `DAYS / NETWORKDAYS` | Tenure calculation |

**Skills:** XLOOKUP · INDEX/MATCH · IF/IFS · SUMIF · COUNTIF · Error Handling

---

### 4. 🎨 Sales Dashboard — Conditional Formatting & Charts

**File:** `Conditional_Formatting_Project.xlsx`

12-month sales visualization for Dunder Mifflin paper products with advanced formatting.

**Key Features:**
- Color-scale CF highlighting top/bottom performers
- Data bars for quick visual comparison
- Bar + Line charts for monthly trend analysis
- Year-end totals with auto-calculation

**Products Tracked:** Paper (5,071 units) · Manila Folders (1,583) · Printers (667)

**Skills:** Conditional Formatting · Color Scales · Data Bars · Chart Design
